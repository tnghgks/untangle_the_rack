## 1. 컨셉

| 항목 | 내용 |
|---|---|
| 한 줄 피치 | 빈 랙 하나에서 시작해 서버와 GPU를 직접 사서, 끼우고, 선을 꽂아 서버실을 키우는 방치형 게임 |

| 화면 ✅ | 완전 3D. 빈 랙이 전경으로 보이고, 카메라로 랙 앞·뒤·옆을 돌아봄 |

| 수익 ✅ | 게임을 켜 둔 동안에만 초 단위로 쌓임. **오프라인 수익 없음** |
| 플랫폼 | 웹, 데스크톱 마우스 우선 (기존과 같음) |

### 1.1 디자인 기둥

1. **켜 두면 돈이 쌓인다**: 숫자가 오르는 걸 보는 방치형의 기본 재미
2. **증설은 손으로 한다**: 구매 버튼으로 끝나지 않고, 장비를 랙에 끼우고 전원선·랜선을 직접 꽂아야 돌아감
3. **엉키면 손해, 정리하면 이득**: 장비가 늘수록 선이 엉키고, 엉킨 랙은 열이 차서 수익이 줄어듦 → 이전 게임의 정리 재미가 경제와 연결됨

## 2. 코어 루프

```
[켜 둠] 장비가 돌며 수익 쌓임 (초당 N원)
   ↓ 돈이 모임
[구매] 상점에서 장비·케이블·부품 구매 → 손에 들림(설치 대기)
   ↓
[설치] 랙 빈 칸에 장비 끼우기 → 전원선(PDU) 연결 → 랜선(스위치) 연결 → 전원 켜기
   ↓ 부팅 완료
[수익 증가] → 랙이 꽉 차거나 포트·전원이 부족해지면 스위치·PDU·랙 증설
   ↺
[관리] 엉킨 선 정리(냉각 보너스), 장애(빠진 선·고장 포트) 수리
```

| 주기 | 플레이어가 하는 일 |
|---|---|
| 몇 초 | 수익 숫자가 오르는 걸 봄 |
| 1~5분 | 다음 장비 살 돈이 모임 → 사서 설치 (30초~1분 손 작업) |
| 10~30분 | 스위치 포트·PDU 용량이 부족해짐 → 기반 장비 증설, 선 정리 |
| 장기 | 랙 증설, 고급 GPU, 서버실 확장 |

### 2.1 시작 상태 ✅

빈 랙에 **스위치 1대 + 엔트리 서버 1대**가 이미 연결되어 돌고 있고, 초당 1원을 번다. 시작 돈 300원으로 엔트리 서버·케이블을 바로 사서 첫 설치를 해 볼 수 있다 (10-25).

## 4. 설치 흐름

```
상점에서 구매 → 장비가 '손에 든' 상태
  → 랙 빈 칸으로 가져가면 들어갈 자리(U 높이) 미리보기 → 클릭으로 밀어 넣기
  → 장비 뒷면에 전원·랜 포트 표시 (빈 포트는 깜빡임)
  → 전원선: PDU 콘센트 ↔ 장비 전원 포트
  → 랜선: 스위치 포트 ↔ 장비 랜 포트
  → 전원 버튼 → 부팅(몇 초, LED) → 수익 시작
```

- 상태등은 앞면·뒷면 둘 다 (10-25): 초록 가동 · 노랑 부팅 · 파랑 꺼져 있지만 배선 완료(켜면 가동) · 빨강 켰는데 안 돎(전기·네트워크 없음) · 어둠 꺼짐·배선 덜 됨
- 장비 앞면은 전원 버튼·LED, **배선은 뒷면** → 카메라를 랙 뒤로 돌려 작업 (완전 3D가 필요한 이유)
- 잘못 꽂아도 막지 않음 (이전 게임 원칙 유지): 다른 장비 포트, 용량 넘는 PDU 등은 경고만 하고 그 장비가 안 돌거나 PDU 차단기가 내려감

### 4.1 제약 (장비가 늘수록 하나씩 등장)

| 제약 | 결과 | 해결 |
|---|---|---|
| 스위치 포트 부족 | 새 서버를 연결할 곳이 없음 | 스위치 증설·교체 |
| PDU 용량 초과 | 차단기 내려감 → 그 PDU 장비 모두 꺼짐 | PDU 추가, 분산 연결 |
| 랙 U 부족 | 장비를 끼울 자리 없음 | 랙 증설 |
| 발열 | 수익 감소(스로틀링) | 선 정리, 냉각 장비, 장비 배치 |

## 5. 정리와 발열

이전 게임의 정리 규칙을 경제에 연결하는 부분.

- 랙마다 **공기 흐름 점수**: 뒷면 케이블이 팬 앞을 가리거나 엉켜 있을수록 낮음
- 발열 = 장비 발열 합 × (1 − 냉각) × (엉킴 보정)
- 발열이 기준을 넘으면 장비 수익 −10% ~ −50% (스로틀링), 아주 높으면 장애 확률 상승
- 정리 행동: 벨크로로 뒷면 기둥에 묶기, ~~케이블 매니저(옆면 거치)~~ → 1U 가로 케이블 매니저 고리에 걸기 (10-26) → 공기 흐름 회복
- (안) 정리 완료된 랙은 "정리 보너스" +10% 수익. 전후 비교 캡처 유지

✅ 정리 기준은 **공기 흐름**: 팬 영역(장비 뒷면 배기구 앞 상자)을 지나는 케이블 길이 + 엉킴으로 점수를 매김. 이전 게임의 "불필요한 교차" 판정은 쓰지 않음 (10-24 결정)

✅ 구현 (10-25): 배기 통로 = 랙 폭 × 바닥~꼭대기, 뒷면에서 10cm 떨어진 곳부터 60cm 뒤까지. 그 안을 지나는 꽂힌 케이블 길이 L로 공기 흐름 = 1 − L/4m, 수익 × (1 − 0.5 × (1 − 공기 흐름)). 뒷면 10cm 안쪽은 세지 않음 — 뒷면에 붙어 지나가는 선은 배기를 막지 않으므로. 시작 상태(2m 3개) 공기 흐름 약 23% → 셋 다 기둥에 끌어다 벨크로로 묶으면 약 94% (브라우저). 장비 발열·냉각 모듈은 아직 식에 없음

✅ 벨크로 (10-25, 손 배선 방식): 한 손으로 대고 다른 손으로 감기. 벨크로 도구(2)로 케이블 가운데를 끌어 뒷면 기둥 위에 커서를 대면 잡은 점이 기둥 겉면에 붙고 반투명 띠가 감길 자리를 보여 줌 → 든 채로 **Space 또는 오른쪽 클릭**하면 그 높이에 띠가 감기고 선을 놓음. 같은 높이(3cm 안)에 띠가 있으면 그 띠에 더 묶어 다발. 세로 기둥이라 그냥 놓으면 미끄러져 내려 "걸쳐 놓고 나중에 클릭"은 안 됨(브라우저 확인). 빈손으로 기둥을 클릭하면 이미 닿아 있는 선을 묶음. 띠는 기둥 중심에서 수평 7cm·위아래 5cm 안을 지나는 케이블을 가닥마다 가장 가까운 마디 하나씩 잡아 기둥 겉면에 붙여 고정 → 한 띠로 여러 가닥을 다발로. 걸친 선이 없으면 빈 띠는 안 감김. 기둥 위에 커서를 올리면 반투명 띠로 감길 자리 미리보기, 감긴 띠를 다시 클릭하면 풀림. 벨크로 도구로도 케이블을 끌 수 있음(기둥 위 클릭만 띠). 커넥터 옆 2마디는 못 묶고, 다른 고정점까지 케이블이 모자라면 거절. 손으로 세게 당기면(15cm 넘게) 가장 가까운 묶음이 먼저 떨어짐. 저장은 케이블마다 묶인 마디와 자리 — 같은 기둥·높이의 묶음이 한 띠

✅ 케이블 매니저 (10-26): 상점에서 사서 랙 칸에 끼우는 1U 부품(전기·포트 없음). 뒷면 5cm 뒤에 고리 5개가 가로로(x −0.2 ~ 0.2m, 10cm 간격) — 배기 통로 앞이라 건 선은 막힘으로 안 셈. 거는 손은 벨크로와 같음: 케이블 가운데를 끌어 고리에 커서를 대면 손이 고리 중심에 붙고 고리가 파랗게 빛남 → 든 채로 **Space 또는 오른쪽 클릭**. 고리 중심 5cm 안의 다른 선도 함께 걸림(한 고리에 여러 가닥, 조금씩 비켜 놓음). 빈손으로 고리를 클릭하면 걸린 선을 모두 빼고(주황 강조), 비어 있으면 닿아 있는 선을 검. 손·벨크로 도구 둘 다에서 됨(따로 도구 없음). 벨크로와 차이: 기둥(랙 양 끝)이 아니라 랙 가운데 원하는 높이에 고정점을 만듦, 대신 1U와 돈을 씀. 높이가 효과를 가름 — 시작 방에서 세 가닥을 하나씩 걸면 U2 23→24%, U10 →70%, U15 →95%, U20 →100% (헤드리스). 남는 길이가 고리 아래로 늘어져야 바닥에 안 깔림. 매니저를 빼거나 팔면 걸린 선이 풀림. 저장은 묶음(Tie)에 고리 id를 붙여 — 불러올 때 그 매니저가 없으면 버림. 가격 100원(×1.25 성장, 10-26 사용자 확정)

✅ 막힘 표시 (10-25): 배기 통로를 막는 케이블 토막(꽂힌 케이블만, 공기 흐름 계산과 같은 기준)이 주황빛으로 깜빡임. 빨간 랜선과 헷갈리지 않게 고정색 대신 깜빡임

(첫 구현 기록: 클릭 한 번에 기둥의 닿는 가장 높은 곳으로 자동으로 끌어올려 묶었음 — 플레이 피드백 "너무 자동이라 직접 하는 맛이 없음"으로 교체. 측정: 마디 높이 그대로 묶으면 3.09 → 3.30m로 오히려 늘고, 끌어올리면 0.12m)

## 6. 3D 케이블 시스템 ✅ 완전 3D

기존 코드는 랙 정면 평면(x·y) + 얇은 깊이층이었다. 완전 3D는 **새로 만드는 핵심 기술이자 가장 큰 리스크**라 가장 먼저 프로토타입한다.

### 6.1 물리

| 항목 | 방향 |
|---|---|
| 적분 | Verlet 3D (기존 구조·상수 감각 재사용: 길이 제약, 굽힘 강성, 굽힘 기억, 감쇠, 60Hz 고정 스텝) |
| 충돌 | 케이블 = 캡슐(선분+반지름) 사슬. 랙·장비·바닥 = 상자. 캡슐↔상자 밀어내기 |
| 케이블끼리 | ~~캡슐↔캡슐 밀어내기 + 마찰~~ → 안 만듦. 케이블은 랙·장비·바닥 상자만 충돌 (10-25 플레이 후 결정) |
| 터널링 | 한 스텝 이동량 제한 + 반복 횟수. 잡은 점은 손을 일정 속도까지만 따라감 |
| 성능 목표 | 랙 1개 케이블 50가닥, 60fps (❓ 실측으로 확정) |

### 6.2 마우스 조작 (깊이를 어떻게 잡나)

- 잡을 때: 화면 광선으로 케이블·커넥터를 집음
- ✅ 끄는 동안: 잡은 점은 **카메라를 바라보는 평면** 위에서 움직이고, 휠로 앞뒤 이동. 포트 근처에선 포트로 빨려 들어가는 자석 보정
- 랙 앞면·뒷면 작업 위치로 카메라가 스냅하는 "작업 시점" 버튼 제공 (자유 회전은 유지)
- ✅ 카메라 (10-25 플레이 피드백): 회전 = **가운데 버튼 드래그**, 이동 = 오른쪽 드래그 또는 Shift+왼쪽 드래그, 줌 = 휠. 왼쪽 드래그 회전은 없음 → 왼쪽은 케이블 잡기·클릭 전용
- ✅ 올리기(hover): 클릭할 수 있는 것은 은은하게 밝히고 커서를 바꿈 — 전원 버튼·장비 `pointer`, 케이블 `grab`. 장비를 든 동안은 `copy`

### 6.3 커넥터와 포트

- 커넥터 종류: 랜(RJ45), 전원(C13/C14). 종류가 다른 포트엔 안 꽂힘
- 꽂기: 커넥터를 포트 근처에 놓으면 스냅 (기존 꽂기 판정 반경 개념 유지). 딸깍 소리
- ✅ 뽑기 (10-25): 꽂힌 커넥터를 **직접 잡고 끌어야**(6px 넘게) 뽑힘. 클릭만 하거나 케이블 가운데를 당기면 안 뽑히고 손이 닿는 거리에서 멈춤 (벨크로는 세게 당기면 떨어짐)
- ✅ 산 케이블 (10-25): 사자마자 손 도구로 바뀌고 한쪽 커넥터가 커서를 따라옴(버튼 안 눌러도). 포트 위에서 클릭하면 꽂힘, 빈 곳 클릭·Esc는 내려놓기. 나머지 끝은 랙 뒤 바닥
- ✅ 상태등은 앞면·뒷면 둘 다 (색은 4장) → 뒷면에서 배선하면서 바로 결과를 봄

### 6.4 케이블 길이 ✅

- ✅ 케이블은 **2m 고정**. 남는 길이는 고리로 늘어져 공기 흐름 감점의 원인 → 벨크로로 뒷면 기둥에 묶어 정리 (5장)
- ~~줄이기 도구~~ → 제거 (10-25 사용자 결정). 옛 저장의 `length`는 무시하고 2m로 불러옴
