### 1.1 디자인 기둥

1. **켜 두면 돈이 쌓인다**: 숫자가 오르는 걸 보는 방치형의 기본 재미
2. **증설은 손으로 한다**: 구매 버튼으로 끝나지 않고, 장비를 랙에 끼우고 전원선·랜선을 직접 꽂아야 돌아감
3. **엉켜도 손해는 없고, 정리하면 이득(전력 여유)**: 장비가 늘수록 선이 엉키지만 벌은 없음. 정리하면 전력이 줄어 같은 PDU에 서버를 더 꽂을 수 있음 → 이전 게임의 정리 재미가 경제와 연결됨 (11-09 변경)

## 2. 코어 루프

```
[켜 둠] 장비가 돌며 수익 쌓임 (초당 N원)
   ↓ 돈이 모임
[구매] 상점에서 장비·케이블·부품 구매 → 손에 들림(설치 대기)
   ↓
[설치] 랙 빈 칸에 장비 끼우기 → 전원선(PDU) 연결 → 랜선(스위치) 연결 → 전원 켜기
   ↓ 부팅 완료
[수익 증가] → 랙이 꽉 차거나 포트·전원이 부족해지면 스위치·PDU·랙 증설
   ↺
[관리] 엉킨 선 정리(냉각 보너스), 장애(빠진 선·고장 포트) 수리
```

| 주기 | 플레이어가 하는 일 |
|---|---|
| 몇 초 | 수익 숫자가 오르는 걸 봄 |
| 1~5분 | 다음 장비 살 돈이 모임 → 사서 설치 (30초~1분 손 작업) |
| 10~30분 | 스위치 포트·PDU 용량이 부족해짐 → 기반 장비 증설, 선 정리 |
| 장기 | 랙 증설, 고급 GPU, 서버실 확장 |

### 2.1 시작 상태 ✅

빈 랙에 **스위치 1대 + 엔트리 서버 1대**가 이미 연결되어 돌고 있고, 초당 1원을 번다. 시작 돈 300원으로 엔트리 서버·케이블을 바로 사서 첫 설치를 해 볼 수 있다 (10-25).

### 3.2 수익 시간 처리 ✅

- ✅ 창을 닫으면 수익 없음. 다시 켜면 그 시점부터 다시 쌓임
- ✅ **탭이 백그라운드여도 페이지가 열려 있으면 수익이 쌓임**. 실제 시간(`Date.now`) 기준으로 계산
  - 브라우저는 숨긴 탭의 rAF를 멈추고 타이머를 늦추므로, 수익은 프레임 수가 아니라 "마지막 계산 시각과 지금의 차이"로 더함
  - 탭이 다시 보이면 밀린 시간만큼 한 번에 더함 (물리는 기존처럼 최대 4스텝만 따라잡고, 수익만 실제 시간으로)

- 진행 상태(돈·장비·배선)는 저장. 저장 안 하는 건 "꺼져 있던 동안의 수익"뿐

## 4. 설치 흐름

```
상점에서 구매 → 장비가 '손에 든' 상태
  → 랙 빈 칸으로 가져가면 들어갈 자리(U 높이) 미리보기 → 클릭으로 밀어 넣기
  → 장비 뒷면에 전원·랜 포트 표시 (빈 포트는 깜빡임)
  → 전원선: PDU 콘센트 ↔ 장비 전원 포트
  → 랜선: 스위치 포트 ↔ 장비 랜 포트
  → 전원 버튼 → 부팅(몇 초, LED) → 수익 시작
```

- 상태등은 앞면·뒷면 둘 다 (10-25): 초록 가동 · 노랑 부팅 · 파랑 꺼져 있지만 배선 완료(켜면 가동) · 빨강 켰는데 안 돎(전기·네트워크 없음) · 어둠 꺼짐·배선 덜 됨
- 장비 앞면은 전원 버튼·LED, **배선은 뒷면** → 카메라를 랙 뒤로 돌려 작업 (완전 3D가 필요한 이유)
- 잘못 꽂아도 막지 않음 (이전 게임 원칙 유지): 다른 장비 포트, 용량 넘는 PDU 등은 경고만 하고 그 장비가 안 돌거나 PDU 차단기가 내려감

### 4.1 제약 (장비가 늘수록 하나씩 등장)

| 제약 | 결과 | 해결 |
|---|---|---|
| 스위치 포트 부족 | 새 서버를 연결할 곳이 없음 | 스위치 증설·교체 |
| PDU 용량 초과 | 차단기 내려감 → 그 PDU 장비 모두 꺼짐 | PDU 추가, 분산 연결 |
| 랙 U 부족 | 장비를 끼울 자리 없음 | 랙 증설 |
| 전력 여유 | PDU 용량이 빨리 참 (벌은 아님) | 선 정리(전력 −15%), PDU 추가, 분산 연결 |

## 5. 정리와 전력

이전 게임의 정리 재미를 경제에 연결하는 부분. 11-09에 방식을 통째로 바꿨다 (설계: `docs/superpowers/specs/2026-11-09-cable-tidy-redesign-design.md`).

- ✅ **엉켜도 손해는 없다.** 정리하지 않아도 벌이 없고, 정리하면 전력 여유가 생기는 이득만 있음
- ✅ 흐름: 선을 꽂음 → 늘어진 선의 가운데를 잡아 **가이드(케이블 매니저) 하나에 끌어다 놓음** → 게임이 나머지 길을 찾아 줌(가이드 최대 3개 경유) → 벨크로 도구(2)로 다발을 **클릭** → 띠가 감기고 반짝이며 "탁" 소리, 그 순간 상단 전력 숫자가 내려감. 묶는 순간 글씨는 안 뜸
- ✅ 가이드 = 상점에서 사서 다는 1U 가로 케이블 매니저(랙 칸)와 세로 케이블 매니저(랙 옆면). 가격 100원(×1.25 성장) 그대로, 랙에 처음부터 달린 가이드는 없음
- ✅ 경로 찾기: 놓은 가이드를 반드시 지나는 양 끝 포트 경로를 고름. 2m 안 경로가 있으면 그중에서, 없으면 길이와 상관없이 그 가이드 하나만 지나는 가장 짧은 경로 (6.4). 양 끝이 다 꽂혀 있지 않으면 거절 — 선이 제자리로 돌아가고 가이드가 짧게 빨갛게 깜빡임(글씨 없음)
- ✅ 상태 둘: **반쯤 정리**(가이드에 들어감, 선끼리 살짝 벌어지고 약간 구불거림, 물리에서 빠져 경로 길이에 딱 맞게 그려짐) → **묶음**(벨크로로 감김, 곧고 나란함)
- ✅ 묶는 단위는 **가이드 구간 하나**: 벨크로를 대면 그 구간을 지나는 다발만 감김. 정확히 겨냥할 필요 없고 실패하지 않음. 이미 묶인 구간에 새 선이 들어오면 기존 선은 묶인 채 그대로, 새 선만 반쯤 정리로 붙고 다시 대면 새 선까지 감김
- ✅ 풀림: 경로에 든 선을 잡아 끌면 경로에서 빠져 다시 물리 로프. 경로가 지나는 매니저를 팔거나 커넥터를 뽑아도 풀림. 옛 저장의 `ties`는 버리고 선은 늘어진 채로 불러옴

### 5.1 전력 보상 ✅

- 장비의 실제 전력 = 정격 전력 × (1 − `TIDY_POWER_CUT` × 정리 비율). `TIDY_POWER_CUT` = **15%** (첫 값, 플레이로 조정)
- 선 하나의 정리 정도 = 그 선이 지나는 가이드 구간 중 묶인 구간의 비율(0~1). 일부만 묶으면 비례해서 부분 보상. 장비의 정리 비율 = 그 장비에 꽂힌 선들의 정리 정도 평균 (선은 양 끝 장비 모두에 셈)
- 가이드에 안 넣은 선과 반쯤 정리(안 묶은) 구간은 0 — 묶는 행동에 보상을 몰아줌
- 전력은 PDU 용량이라 줄면 같은 PDU에 서버를 더 꽂을 수 있음. 정리가 풀려 용량을 넘으면 기존 규칙대로 차단기가 내려가고 PDU 경고가 미리 알려 줌
- 공기 흐름·스로틀링(수익 감소)·상단 바 공기 흐름 %·막힘 깜빡임은 모두 제거

(10-25~26 기록, 11-09 교체: 옛 방식은 공기 흐름 점수로 수익을 최대 −50% 깎고, 벨크로로 뒷면 기둥에 띠를 감거나 매니저 고리에 케이블을 한 가닥씩 끌어 대 Space·오른쪽 클릭으로 걸었음. 한 가닥씩 정밀하게 겨냥해야 하고 결과가 정리된 것처럼 안 보여 교체. 자세한 옛 수치는 git 기록 참고)

### 5.2 전용 랙·짝 연결 ✅ (11-11)

설계: `docs/superpowers/specs/2026-11-11-rack-theme-pair-design.md`. 규칙은 모두 **보너스만** — 안 지켜도 손해 없음. 새 장비·포트·케이블 없음, 저장 형식 그대로.

- **전용 랙**: 한 랙의 서버가 2대 이상이고 모두 같은 종류 → 그 랙 서버 수익 **+10%**. 그 종류를 하나 더 끼울 자리가 없으면 **꽉 찬 전용 +25%** (둘 중 하나). 스위치·PDU·매니저는 셈에서 빠지고, 서버가 켜졌는지는 안 봄
- **짝 연결**: GPU 서버와 스토리지 서버의 랜 포트가 케이블 하나로 직접 이어지고 둘 다 가동 중 → 둘 다 **+15%**. 다른 랙끼리도 됨
- 수익 = 기본 × (1 + 전용 + 짝). 예: 꽉 찬 GPU 전용 랙 + 짝 = ×1.40
- 보이는 것: 랙 위 가로판 앞·뒤 색 띠 (엔트리 은색 · 웹 하늘 · 스토리지 주황 · GPU 보라, 꽉 차면 밝게). 생기는 순간 반짝 + "띵동", 글씨 없음 (불러오기 땐 연출 없이 띠만). 정보 카드 수익 줄에 `(전용 랙 +10% · 짝 +15%)`, 짝이면 `짝: <장비>`. 가이드 패널 "보너스"

## 6. 3D 케이블 시스템 ✅ 완전 3D

기존 코드는 랙 정면 평면(x·y) + 얇은 깊이층이었다. 완전 3D는 **새로 만드는 핵심 기술이자 가장 큰 리스크**라 가장 먼저 프로토타입한다.

### 6.1 물리

| 항목 | 방향 |
|---|---|
| 적분 | Verlet 3D (기존 구조·상수 감각 재사용: 길이 제약, 굽힘 강성, 굽힘 기억, 감쇠, 60Hz 고정 스텝) |
| 충돌 | 케이블 = 캡슐(선분+반지름) 사슬. 랙·장비·바닥 = 상자. 캡슐↔상자 밀어내기 |
| 케이블끼리 | ~~캡슐↔캡슐 밀어내기 + 마찰~~ → 안 만듦. 케이블은 랙·장비·바닥 상자만 충돌 (10-25 플레이 후 결정) |
| 터널링 | 한 스텝 이동량 제한 + 반복 횟수. 잡은 점은 손을 일정 속도까지만 따라감 |
| 성능 목표 | 랙 1개 케이블 50가닥, 60fps (❓ 실측으로 확정) |

### 6.2 마우스 조작 (깊이를 어떻게 잡나)

- 잡을 때: 화면 광선으로 케이블·커넥터를 집음
- ✅ 끄는 동안: 잡은 점은 **카메라를 바라보는 평면** 위에서 움직이고, 휠로 앞뒤 이동. 포트 근처에선 포트로 빨려 들어가는 자석 보정
- 랙 앞면·뒷면 작업 위치로 카메라가 스냅하는 "작업 시점" 버튼 제공 (자유 회전은 유지)
- ✅ 카메라 (10-25 플레이 피드백): 회전 = **가운데 버튼 드래그**, 이동 = 오른쪽 드래그 또는 Shift+왼쪽 드래그, 줌 = 휠. 왼쪽 드래그 회전은 없음 → 왼쪽은 케이블 잡기·클릭 전용
- ✅ 올리기(hover): 클릭할 수 있는 것은 은은하게 밝히고 커서를 바꿈 — 전원 버튼·장비 `pointer`, 케이블 `grab`. 장비를 든 동안은 `copy`

### 6.3 커넥터와 포트

- 커넥터 종류: 랜(RJ45), 전원(C13/C14). 종류가 다른 포트엔 안 꽂힘
- 꽂기: 커넥터를 포트 근처에 놓으면 스냅 (기존 꽂기 판정 반경 개념 유지). 딸깍 소리
- ✅ 뽑기 (10-25): 꽂힌 커넥터를 **직접 잡고 끌어야**(6px 넘게) 뽑힘. 클릭만 하거나 케이블 가운데를 당기면 안 뽑히고 손이 닿는 거리에서 멈춤 (벨크로는 세게 당기면 떨어짐)
- ✅ 산 케이블 (10-25): 사자마자 손 도구로 바뀌고 한쪽 커넥터가 커서를 따라옴(버튼 안 눌러도). 포트 위에서 클릭하면 꽂힘, 빈 곳 클릭·Esc는 내려놓기. 나머지 끝은 랙 뒤 바닥
- ✅ 상태등은 앞면·뒷면 둘 다 (색은 4장) → 뒷면에서 배선하면서 바로 결과를 봄

### 6.4 케이블 길이 ✅

- ✅ 늘어진(물리) 케이블은 **2m 고정**. 가이드 경로에 든 선은 2m 제한을 받지 않음 — 매니저를 어느 높이에 달아도 들어감 (사용자 결정 11-09). 경로는 2m 안 경로를 우선하고, 없으면 놓은 가이드 하나만 지나는 가장 짧은 경로. 장비 옮기기·저장 복원 때도 길이 때문에 경로가 실패하지 않음 (5장)
- ~~줄이기 도구~~ → 제거 (10-25 사용자 결정). 옛 저장의 `length`는 무시하고 2m로 불러옴
