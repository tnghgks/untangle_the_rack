# Untangle the Rack

빈 랙 하나에서 시작해 서버와 GPU를 직접 사서, 끼우고, 선을 꽂아 서버실을 키우는 웹 3D 방치형 게임입니다.

**플레이:** https://tnghgks.github.io/untangle_the_rack/

## 게임 소개

- **켜 두면 돈이 쌓여요.** 게임을 켜 둔 동안 장비가 초 단위로 수익을 냅니다. 오프라인 수익은 없습니다.
- **증설은 손으로 해요.** 상점에서 산 장비를 랙 빈 칸에 끼우고, 전원선은 PDU에, 랜선은 스위치에 직접 꽂은 뒤 전원을 켜야 돌아갑니다.
- **엉키면 손해, 정리하면 이득이에요.** 랙 뒤로 늘어진 케이블은 배기를 막아 공기 흐름이 떨어지고 수익이 최대 50% 줄어듭니다. 벨크로나 케이블 매니저로 정리하면 회복됩니다.

시작할 때 스위치 1대와 엔트리 서버 1대가 이미 돌고 있고, 300원을 들고 시작합니다.

## 조작

| 동작 | 입력 |
|---|---|
| 카메라 회전 / 이동 / 확대 | 가운데 버튼 드래그 / 오른쪽 또는 Shift+왼쪽 드래그 / 휠 |
| 장비 설치 | 상점에서 고른 뒤 랙의 빈 칸 클릭 |
| 장비 옮기기 | 장비를 끌어 다른 칸에 놓기 (닿는 케이블은 그대로 꽂힘) |
| 케이블 꽂기 | 커넥터를 끌어 포트 위에 놓기 · 끄는 중 휠로 앞뒤 밀기 |
| 케이블 뽑기 | 꽂힌 커넥터를 직접 잡고 끌기 |
| 벨크로 (2) | 케이블을 뒷면 기둥에 대고 Space(또는 오른쪽 클릭) · 띠 클릭으로 풀기 |
| 케이블 매니저 | 케이블을 고리에 대고 Space(또는 오른쪽 클릭) · 고리 클릭으로 빼기 |
| 판매 (3) | 장비나 케이블 클릭 → 산 값의 50% 환급 |
| 정보 카드 | 장비 클릭 (켜기·끄기·빼기) |
| 취소 | Esc |

자세한 규칙은 게임 상단 바의 **가이드** 버튼에서 볼 수 있습니다.

## 개발

Node 22 기준입니다.

```bash
npm install
```

```bash
npm run dev
```

```bash
npm test
```

```bash
npm run build
```

- `?debug`: 디버그 표시를 켭니다.
- `?reset`: 저장(localStorage)을 지우고 새로 시작합니다. 진행 중인 저장이 사라지니 주의하세요.

`main`에 push하면 GitHub Actions가 테스트·빌드 후 GitHub Pages에 배포합니다 ([deploy.yml](.github/workflows/deploy.yml)).

## 구조

| 경로 | 내용 |
|---|---|
| `src/cable` | 3D 케이블 로프 물리, 꽂기, 충돌, 벨크로, 케이블 매니저 |
| `src/rack` | 랙·장비 메시, 칸 배치 |
| `src/game` | 경제, 전원(PDU), 발열·공기 흐름, 저장 |
| `src/view` | three.js 씬, 카메라, 마우스 입력(끌기·고르기) |
| `src/ui` | HUD, 상점, 정보 카드 |
| `src/data` | 장비 카탈로그, 단위 |
| `tests` | Vitest 헤드리스 테스트 |
| `docs` | [기획서(GDD)](docs/GDD-피벗-서버실-방치형.md), [MVP 구현 계획](docs/MVP-구현계획.md) |
